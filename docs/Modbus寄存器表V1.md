# Modbus RTU 寄存器表 V1

2026-10-20。地址均为 PDU 中的 **零起始地址**，不是 30001/40001 展示编号。此文件是新协议设计，实际部署与验收状态以迁移记录为准。

总线固定 115200 / 8N2（8 数据位、无校验、2 停止位），半双工单主站。星火地址 1，龙芯地址 2；0 为广播，仅允许星火 LED 写入且不应答，248–255 不使用。寄存器内大端；32 位值高寄存器在前；有符号量为二进制补码。CRC16 低字节先发。每次读请求取得一份缓存快照，不在应答路径重探传感器或读取 Linux 系统文件。

支持 04 读输入寄存器；星火另支持 03 读 LED 保持寄存器和 06 写单保持寄存器。未知功能返回 01、非法地址/跨出映射返回 02、非法数量/值/请求长度返回 03；CRC 错误、其他站地址和广播读取不应答。协议处理器接受标准数量 1–125，具体映射边界仍须满足。

共同输入头（两站 04）：

| 地址 | 内容 | 格式/单位 |
|---|---|---|
| 0 | 映射版本 | 0x0100 |
| 1 | 节点种类 | 星火=1，龙芯=2 |
| 2 | 节点地址 | 1 或 2 |
| 3 | 有效性位 | 星火 bit0 温湿度、bit1 IMU；龙芯 bit0 CPU、bit1 内存、bit2 负载、bit3 uptime |
| 4–5 | 采样序号 | u32；星火为 IMU 成功采样序号 |
| 6–7 | 节点系统运行时间 | u32 秒 |
| 8–9 | 样本年龄 | u32 毫秒；星火为 IMU 年龄，未取得过样本为 0xffffffff |

星火输入寄存器（04 一次读 0 起始、20 个寄存器）：

| 地址 | 内容 | 格式/单位 |
|---|---|---|
| 10 | 环境温度 | i16，0.01℃ |
| 11 | 相对湿度 | u16，0.01%RH |
| 12 | LED 状态 | 0/1 |
| 13、14、15 | ax、ay、az | i16，16384 LSB/g，±2g |
| 16、17、18 | gx、gy、gz | i16，131 LSB/(°/s)，±250°/s |
| 19 | 保留 | 0 |

星火保持寄存器 0（03/06）：LED，允许值 0 或 1，其他值异常 03。有效位为 0 时读数字段不作为有效测量；有效零温度/湿度/轴数据仍允许。温湿度沿用 3 秒有效窗口，IMU 沿用 200ms 缓存有效窗口。

龙芯输入寄存器（04 一次读 0 起始、34 个寄存器）：

| 地址 | 内容 | 格式/单位 |
|---|---|---|
| 10 | CPU 使用率 | u16，0.01% |
| 11 | 一分钟负载 | u16，0.001 |
| 12–13 | 总内存 | u32，KiB |
| 14–15 | 可用内存 | u32，KiB |
| 16–17 | 从站进程运行时间 | u32 秒 |
| 18–19 | 请求数 | u32 |
| 20–21 | 成功应答数 | u32；当前应答发送前的快照 |
| 22–23 | CRC 错误数 | u32 |
| 24–25 | 帧错误数 | u32 |
| 26–27 | 发送错误数 | u32 |
| 28–29 | 接收字节数 | u32 |
| 30–31 | 发送字节数 | u32 |
| 32–33 | 拒绝请求数 | u32 |

龙芯样本超过 3 个采样周期即清有效性位；通信在线与系统指标新鲜度分别判断。不支持 LED 保持寄存器。

迁移不改变 UI、TF 文件和 MQTT 数据模型；主站把寄存器解码到既有本地结构。旧 AA55 辅助编解码如保留，仅作为兼容工具，不计入新主站周期采集链路。

规范：[应用协议 V1.1b3](https://www.modbus.org/file/secure/modbusprotocolspecification.pdf)、[串行链路指南 V1.02](https://www.modbus.org/file/secure/modbusoverserial.pdf)。高于 19200bps 的 RTU 帧间保护采用至少 1.75ms，平台以至少 2ms 调度窗口实现；微秒级字符间隔容差及物理总线波形需要独立测量，不能仅凭软件互通宣称通过一致性认证。
