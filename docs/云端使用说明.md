# 云后台和微信小程序

根目录 `backend/`、`miniprogram/`、`Dockerfile` 与原云托管布局兼容。历史部署说明见[云托管开通与部署](../云托管开通与部署.md)，数据库备份及隔离恢复见[数据库备份与恢复](../数据库备份与恢复.md)。带日期的旧记录反映当时状态，以根 README 的最新验收结论为准。

1. 使用 `requirements.lock.txt` 安装 Python 依赖；在首次配置时复制 `config.example.json` 为被 Git 忽略的 `config.private.json`，填写本机配置。已有私有配置不要覆盖。
2. 运行 `python -m pytest -q` 和 `node tests/client.test.cjs`。本机启动脚本为 `tools/start_local.ps1`；先配置本地登录令牌及设备主题。
3. 微信开发者工具导入 `miniprogram/`。`miniprogram/config.js` 中是公开路由信息；AppSecret、MQTT 凭据与配对码仅存私有配置或部署环境变量。
4. 云容器使用根目录 Dockerfile 和 `tools/package_cloud.py` 白名单打包；`/health` 是进程存活检查，`/ready` 另外检查数据库、归档工作线程和 MQTT 订阅。

后台仅安排一个采集实例，MQTT 本身为 QoS0。可靠事件在数据库提交后应用确认，普通实时摘要不会自动补全所有断网数据。2026-10-22 的生产 MySQL 是恢复到独立新库进行校验，没有覆盖生产库；实际备份与用户数据不在公开仓库中。
